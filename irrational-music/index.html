Irrational Music — drop-in widget

This whole player is one custom element. No build step, no framework — just the script tag below and the tag itself.

<script src="irrational-music-player.js"></script> <irrational-music-player melody-source="phi" key="D" scale="dorian" tempo="92"> </irrational-music-player>
